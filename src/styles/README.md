# shadcn CSS

`shadcn-tailwind.css` is the unmodified stylesheet from the installed npm package `shadcn@4.22.1`, with one provenance comment added. Upstream repository: https://github.com/shadcn-ui/ui/tree/main/packages/shadcn . MIT notice: `SHADCN-LICENSE.txt`.

The app uses the stylesheet, not the component-generator CLI. Keeping CSS locally avoids installing that CLI and its registry/deepmerge dependencies in the application. This is not a fork of the CLI or a fix for deepmerge. Review upstream CSS changes and retain the licence when updating.
